# D/O taxonomy

Computational depth (D) describes the public inputs available for the computational chain examined in this benchmark. D0 indicates that the examined public record cannot specify that chain at a defensible computational point. D1 provides a near-terminal point that supports final-chain reconstruction. D2 provides an alternatives-by-criteria matrix or equivalent standardized point with the operative weights and aggregation inputs. D3 reaches the earliest public numerical inputs used for the declared reconstruction, together with the method specification needed to attempt it.

Published terminal output (O) describes what the source reports: O0, no evaluable terminal output; O1, a winner only; O2, a complete ranking without a complete comparable score vector; and O3, a complete ranking with terminal numerical outputs.

Computational depth and output availability are assessed separately from terminal evaluability. D3 does not guarantee a finite or uniquely identified decision: NP08 and NP09 are D3/O3 but remain non-evaluable. NP11 has an identified baseline ranking despite nonunique optimal weights and scores. NP10 is D0/O3 because the examined materials lack required inputs. For NP04, the reconstruction uses managers' ratings and published global rough weights to evaluate Rough-WISP; it does not reestimate the upstream BWM optimization.
