# Reproducibility scope

The default route reproduces the benchmark computations from repository-contained extracted and standardized research inputs without requiring third-party publication bytes. It verifies native reconstructions, decision-stability analyses, final source-resolution consistency, and publication-source objects. It does not repeat literature discovery, alter the scientific design, invent missing source data, or replace `NE` cases with surrogate computations.

The NP04 source-workbook comparison is preserved as a source-artifact audit. Because the publisher workbook is not redistributed, the offline route recomputes the primary Eq. (31) branch and integrity-checks the repository's documented source-audit records.

The benchmark is purposive and should not be interpreted as estimating the prevalence of reproducibility or instability across the wider ERP-MCDA literature.
